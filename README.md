\# QA Automation Framework with Playwright \& PyTest
[![Playwright Tests](https://github.com/tadisreelakshmi-debug/qa-automation-project/actions/workflows/playwright.yml/badge.svg)](https://github.com/tadisreelakshmi-debug/qa-automation-project/actions/workflows/playwright.yml)



An end-to-end automated testing suite for web applications built using Python, Playwright, and PyTest, following the Page Object Model (POM) architectural design pattern.



\## Features

\- \*\*Page Object Model (POM)\*\* structure for maintainability and scalability.

\- Automated UI tests for positive login, negative login validation, and cart workflows.

\- Visual HTML test reporting with `pytest-html`.



\## Tech Stack

\- Python

\- Playwright

\- PyTest

\- PyTest-HTML
